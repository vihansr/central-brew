# Central Brew

Central Brew is a small static website for a fictional cafe/coffee shop. The site includes pages for the menu, about, contact, and more.

## Contents
- index.html — homepage
- menu.html — menu page
- about.html — about page
- contact.html — contact page
- assets/ — images and other static assets

## Usage
Open `index.html` in a browser to preview locally, or deploy to any static hosting provider (GitHub Pages, Netlify, Vercel static site, etc.).

## Development
Edit the HTML/CSS files in this repository to update content and styling. Images live in the `assets/` folder.
